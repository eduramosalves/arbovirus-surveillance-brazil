# Arbovirus Surveillance in Brazil — Normalized Analysis Pipeline

Reproducible statistical and geospatial analysis of **Dengue, Chikungunya, and Zika** notifications across the 27 Brazilian federative units, 2016–2025 (monthly grain). All inputs are normalized CSV fact/dimension tables; all outputs (tables, plots, composite figures) are generated by a single orchestrator.

- **Data window:** 2016–2025 (CHIKV starts 2017)
- **Spatial unit:** 27 federative units (UF)
- **Temporal unit:** monthly
- **Run date of the committed outputs:** 2026-05-19

A full narrative of the methods and findings is in [`RESULTS_SUMMARY.md`](RESULTS_SUMMARY.md) (and rendered as `RESULTS_SUMMARY.html`).

## Pipeline stages

`pipelines/run_all.py` executes these in order:

| # | Script | Produces |
|---|---|---|
| 1 | `arbovirus_pipeline_en.py` | Descriptives, Mann-Kendall trends, Spearman climate correlations, Global Moran's I |
| 2 | `arbovirus_geospatial.py` | Choropleth maps, LISA clusters, trend maps |
| 3 | `graphpad_to_python_pipeline.py` | Clinical / demographic plots from GraphPad `.pzfx` data |
| 4 | `bootstrap_ci.py` | Bootstrap 95% CIs alongside normal-approximation CIs |
| 5 | `glm_poisson.py` | Poisson GLM (pooled FE, per-state, lagged) |
| 6 | `glm_quasi_poisson.py` | Quasi-Poisson GLM |
| 7 | `glm_negbin.py` | Negative Binomial GLM (preferred model — see writeup) |
| 8 | `merge_figures.py` | 11 `figures/` composites (`Figure1`–`Figure8`; Figure 6 split into `Figure6a`–`Figure6d`) |

`pipelines/alt_results.py` is a separate, standalone regenerator for the
five alternative-view figures in `figures/` (`trend01_slope_first_last`,
`trend03_sen_dotbar`, `spat01_choropleth_facet`, `spat02_lisa_facet`,
`glm02_caterpillar_temp_irr`). It is not part of `run_all.py` — run it
on demand with `python pipelines/alt_results.py`. See
[`alt_results/README.md`](alt_results/README.md) for what each alternative
replaces.

## Running the analysis

Requires Python 3.10+ with the standard scientific stack plus geospatial libraries.

```bash
pip install pandas numpy scipy statsmodels matplotlib seaborn \
            geopandas libpysal esda pymannkendall openpyxl
```

Then:

```bash
cd pipelines
python run_all.py
```

All scripts read from `../db/` and write to `../outputs/` and `../figures/`. The orchestrator reports `8/8 succeeded` on a clean run.

## Key findings (one-line summary)

- **Dengue** dominates by volume (16.3 M cases) and is the only arbovirus with significant spatial clustering (Moran's I = 0.56) — strong positive temperature association (IRR ≈ 2.1 per °C, NegBin).
- **Chikungunya** shows emerging upward trends in southern states (SC, RS, MS).
- **Zika** has declined since 2016 with weak/inverse climate association — post-epidemic regime.
- **Negative Binomial is the appropriate model family**; Poisson is rejected (dispersion 20×–137,000× the assumption).

Full numbers, CIs, and per-state breakdowns: [`RESULTS_SUMMARY.md`](RESULTS_SUMMARY.md).

## Methodological notes

1. The `Annual_Incidence` column in the source DB was actually *monthly* incidence per 100k — renamed to `Monthly_Inc_per100k`; values unchanged.
2. Both normal-approx and bootstrap (1,000 resamples) CIs are exported. Bootstrap is preferred for Dengue due to right-skew.
3. Monthly observations within a state are autocorrelated; reported SEs assume independence. Clustered/HAC SEs or mixed-effects extensions are recommended for inference-critical claims.
4. Spatial weights: KNN k=4 (point pipeline) and KNN k=5 (polygon pipeline). Queen contiguity falls back to KNN because of island UFs.
